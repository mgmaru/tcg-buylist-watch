# tcg-buylist-watch

カードショップのポケカ買取表を1日1回取得して、価格の変化と店ごとの差を記録します。

フリマで仕入れて店に売るときの「いま、どの店がいくらで買い取るか」を、手で調べずに追えるようにするためのものです。

## 対応している店

| 店 | 取得元 | 件数の目安 | 取れる価格 |
|---|---|---|---|
| カードラッシュ (`cardrush`) | 買取表の公開ページ（100件ずつ、約140ページ） | 約14,000件 | 買取 |
| 晴れる屋2 (`hareruya2`) | 買取リストのページが読み込むJSON（1回） | 約23,500件 | 買取・販売 |

## 使い方

Python 3.10以上で動きます。外部ライブラリは使いません。

```sh
export PYTHONPATH=src

# 全店を取得して data/ に保存（カードラッシュは7分ほどかかります）
python -m buylist_watch fetch

# 1店だけ、最初の3ページだけ試す
python -m buylist_watch fetch --source cardrush --max-pages 3

# ある店の買取価格が、別の店の販売価格より高いカードを探す
python -m buylist_watch compare --min-buy 3000 --top 20

# チェッカーのサイトを _site/ に作る
python -m buylist_watch site

# テスト
python -m unittest discover -s tests
```

## 保存されるデータ

```
data/<店>/latest.csv          最新の全件（毎回上書き）
data/<店>/changes/<日付>.csv   前回から変わった行だけ
data/<店>/meta.json           取得日時と件数
reports/cross_shop.csv        店をまたいだ比較の結果
```

`changes` の `change` 列は次のどれかです。

- `new`：新しく掲載された
- `removed`：掲載がなくなった
- `up` / `down`：買取価格が上がった / 下がった
- `sell`：販売価格だけが変わった

全件を毎日残すとリポジトリがすぐ大きくなるので、履歴は差分だけにしています。

## チェッカー（GitHub Pages）

`web/index.html` が画面で、`site` コマンドが `data/` から `data.json` を作ります。3つの表示があります。

- **チェック**：カード名や型番で探して、店ごとの買取価格、仕入れの上限、出品価格を入れたときの利益、買取価格の推移を見る
- **値動き**：直近7日で買取価格が上がった・下がった・掲載が終わった・新しく載ったカード（買取3,000円以上）
- **店の差**：ある店の買取価格が、別の店の販売価格より高い組み合わせ

仕入れの上限と利益は、状態Aを100%として A-は56%、Bは20% で買い取られる想定です。仮の比率なので、実際の査定とは違うことがあります。出品価格の入力はブラウザにだけ保存されます。

載せるのは買取1,000円以上のカードだけです。

## 定期実行

`.github/workflows/fetch.yml` が毎日 5:17（日本時間）に取得して結果をコミットし、チェッカーを GitHub Pages に公開します。Actions の画面から手動でも実行できます。

Pages を使うには、リポジトリの Settings → Pages で Source を「GitHub Actions」にしてください。非公開リポジトリで Pages を使うには、GitHub の有料プランが必要です。公開したページは、URLを知っていれば誰でも見られます。

## 比較結果を読むときの注意

- 突き合わせは「名前と型番」だけです。1EDと再販、通常と色違いのような仕様違いは区別できません。結果は候補として見て、買う前に両方の店のページで仕様を確かめてください。
- 晴れる屋2の販売価格は、在庫がなくても表示されます。その値段で買えるとは限りません。
- 買取価格は美品が前提です。傷があると大きく下がります。

## 取得の作法

- 取得は1日1回、1件ごとに1.5秒空けます。
- カードラッシュは、robots.txt が禁止している `/api` を使わず、公開ページだけを読みます。
- User-Agent にこのリポジトリのURLを入れています。
- 個人の調査用です。取得したデータの再配布は想定していません。各店の利用規約を確認のうえ使ってください。

## 店を追加するには

`src/buylist_watch/sources/` に、`NAME` と `fetch(fetcher, max_pages)` を持つモジュールを作り、`sources/__init__.py` の `SOURCES` に登録します。`fetch` は `Price` を1件ずつ返します。
